02 · The pages

What each page does

These pages redraw themselves for whichever site is chosen above. Use the menu at the top to switch site from any page.

LiveReading contoursBuild the hill in layers, read landforms, measure gradients and draw sections, see where water runs. LiveSun & climateSun path in 3D, ground shadows on any day, hours of sun, aspect, and rainfall and wind charts from station data. LiveModel kitThe whole site as a laser-cut contour model at 1:100, 1:200, 1:500 or 1:1000: sheets, assembly guide, contour plan and a 3D build guide. LiveYour modelEach student picks a square of the site and makes a contour plan plus laser sheets, a 3D print or a CNC carving at 1:100 to 1:1000. AdvancedAdvancedSections through a 3D scan, projection onto a physical model, and adding a new site. Only when you need them.
03 · For staff

Adding next year's site

A new site needs a terrain STL and a few details. Students can do the same for their own sites; only staff publish to the website.

  1. STL

    Export the terrain as an STL with north up (+Y). QGIS's DEMto3D plugin works well: note the scale (for example 1:200) and any vertical exaggeration. A flat base under the terrain is fine; the page ignores it.

  2. Set up

    Open Add a site, drop in the STL or GeoTIFF lidar tiles, enter the scale, the location and the year, and trace the main features: watercourses, roads, buildings, the site boundary. You can also import them from QGIS as GeoJSON or from CAD as DXF.

  3. Check

    Save it on this computer and open each page. Check a known spot height and the north point before anyone cuts board.

  4. Publish

    Download the site pack, put it in the website's sites/ folder and add one line for it to sites/index.json. Push to GitHub and every student sees it. Earlier years stay listed.

    { "sites": [ { "id": "gleniff-2026", "name": "Gleniff Barytes Mill", "place": "Ballintrillick, Co. Sligo", "year": "2026", "file": "sites/gleniff-2026.json" }, { "id": "new-site-2027", "name": "New site", "year": "2027", "file": "sites/new-site-2027.json" } ] }

Prefer the command line? node tools/stl2pack.js site.stl sites/site.json --name "Site" --scale 200 --lat 54.4 --lon -8.4 makes the same pack without features.
